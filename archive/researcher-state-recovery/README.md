# Researcher state-recovery snapshots

These files are intermediate `state.md` snapshots created when the original autonomous researcher
stopped or failed during step 8. They differ from the final append-only [`state.md`](../../state.md)
and are retained only to preserve the recovery/audit trail. They are not current project status.

- `state-step8-failed-early.snapshot.md` — earliest failed step-8 state.
- `state-step8-fail-fast-agreed.snapshot.md` — state after the fail-fast decision was recorded.
- `state-step8-failed-late.snapshot.md` — later failed step-8 state before successful completion.
